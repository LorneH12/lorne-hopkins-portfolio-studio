# Lorne Hopkins — Portfolio Studio

A separate comparison portfolio. No other portfolio repository is modified.
Plain HTML, CSS and JavaScript: no build tools, framework or package installation required.

## Find what you need

| Location | What to edit |
| --- | --- |
| `index.html` | All page text, section order, links, project tabs and testimonials |
| `css/styles.css` | Colors, spacing, responsive layouts and section overlap |
| `css/fonts.css` | Local font definitions |
| `js/main.js` | Navigation, work tabs and whole-section scroll behavior |
| `assets/` | Every visual asset: portraits, laptop images, headshots, logos and favicon |
| `fonts/` | Locally hosted typefaces and their licenses |
| `EDITING.md` | Step-by-step editing instructions and a section template |

## Preview and publish

Open `index.html` in a browser for a quick preview. For local hosting, run `python -m http.server 8000` from this directory.
GitHub Pages serves `main` from `/ (root)`. Commits to `main` automatically update the website after deployment completes.

## Motion

Only complete section sheets overlap slightly during scrolling (40–80px). Portraits and text remain stationary within their sections. Decorative rings and matte surface textures move gently with scrolling, with foreground rings masked away from content. Sections grow with their content; tall sections remain fully readable before pinning. Reduced-motion preferences turn overlap and decorative movement off.

## Content status

Training images are illustrative scenes. Colleague recommendations are approved by the user and displayed as italic quotations with five-star ratings.
